MADEPICE

1-L'application est construit sous ReactJS.
2-Dependance:{
    browser-router-dom:navigation,
    bootstrap:style,
    fontawesome:icons,
    r18inext:traduction,
}
3-Il se divise en 4 grande partie: Acceuil, A propos, Produit et Contact.

4-Dans la partie produits et detail on utilise une systeme d'objet javascript pour les produits. Ce fichier se nomme data.js avec le structure suivant:

  Cette objet sert généralement comme référence pour les images. Pour modifier les images dans la partie Produit, il faut modifier
    "imgUrl: imgAil_1,"
dans l'objet principale, pour modifier l'image en titre il faut modifier
    "imgUrl_1: imgAil_2,"
5-Chaque produits a une liste de produits pour les différentes texture.
6-Dans la partie détails, on peut modifier les photos dans la gallery en les important au préalable.
7-Pour modifier les textes il faut entrer dans /public/locales et choisir une dossier français ou anglais.
8-Pour que la traduction marche on doit utiliser une même structure d'objet dans toutes les fichiers de traduction
